## 总体问题

1. 底部导航未选中态颜色过浅，文字和图标在浅背景上可读性偏弱。
2. 多个页面顶部留白偏大，首屏信息密度不足，尤其是今天、设置、隐私政策、服务协议。
3. 独立内容页返回能力不统一：登录页和分类管理有返回入口，隐私政策和服务协议没有明显返回按钮。
4. 标题语言不统一，今天页标题仍为英文 `Today`，其他页面为中文。
5. 页面视觉层级不完全统一：设置页是行式列表，登录页是卡片式信息块，隐私/协议页是纯文本页，整体系统感还可以再收敛。

## 逐页点评

### 今天

优点：空状态干净，金额和主操作按钮明确。

问题：
1. 标题使用 `Today`，和中文产品文案不一致。
2. 首屏上半部分空白偏多，最近账单为空时页面显得过轻。
3. `展示最近账单` 像可点击项但视觉反馈不强。
4. 底部导航未选中项太浅。

### 记账

优点：记账入口直接，分类图标识别度较高，数字键盘常驻便于快速输入。

问题：
1. 分类区、备注输入、金额框、数字键盘同时占屏，页面显得拥挤。
2. 右侧滚动条贴边较明显，破坏了图标网格的整洁感。
3. 备注输入框夹在分类和键盘之间，层级不够明确。
4. 数字键盘视觉重量很高，挤压了分类选择区域。

### 统计

优点：月度指标、AI 建议、图表切换、分类排行的结构完整。

问题：
1. 月份左右箭头是独立圆角块，但没有明确点击语义，视觉上像装饰。
2. `AI 统计建议` 黄色按钮视觉权重过高，比核心统计数据更抢眼。
3. 空数据状态占位偏弱，`分类排行` 标题下方缺少有效空态说明。
4. 顶部留白偏大。

### 心愿

优点：目标输入、计划生成、已有心愿卡片流程完整。

问题：
1. 输入框只有 placeholder，缺少固定标签；输入后字段语义可能不够清楚。
2. 顶部表单和下方心愿卡片距离较近，信息密度略高。
3. `生成计划` 视觉权重过强，和卡片操作按钮风格不完全一致。
4. 卡片中文案较长，当前展示显得拥挤。

### 设置

优点：账号信息已经改为普通行，和隐私政策、服务协议、分类管理等行保持一致；分类管理已变成独立入口。

问题：
1. `邀请码` 和 `管理员邀请码` 仍是块状区域，和其他行式设置项的风格差异较大。
2. 账号右侧昵称靠近边缘，长昵称场景需要继续确认截断效果。
3. 顶部留白偏大。
4. 底部导航未选中项仍然偏淡。

### 账号与同步 / 登录

优点：独立登录页方向正确，已展示华为昵称、应用用户 ID、OpenID。

问题：
1. 信息卡和按钮区域视觉上偏厚，和设置页行式风格差异较大。
2. `应用用户 ID 1` 的显示语义不够清楚，建议明确为 `应用用户 ID：1`。
3. OpenID 截断后仍占据一行，但对普通用户价值有限，建议弱化或折叠到详情。
4. 昵称输入框当前只显示 `昵称`，和上方已登录昵称重复，容易让用户误解是否需要再次填写。

### 隐私政策

优点：文案清楚，说明了本地数据、华为账号、服务端同步和图片识别。

问题：
1. 页面没有明显返回按钮，用户需要依赖系统返回。
2. 顶部留白偏大。
3. 正文是整段文本，缺少小标题或分段层级，不利于快速扫描。

### 服务协议

优点：内容简洁，能覆盖用途、用户责任、识别误差和免责说明。

问题：
1. 页面没有明显返回按钮。
2. 顶部留白偏大。
3. 正文缺少小标题，阅读层级偏弱。

### 分类管理

优点：已独立成页面，入口和页面职责清晰；支出/收入切换、添加、图标选择、已有分类展示都在同一页。

问题：
1. 当前选择 `支出` 时，列表底部仍展示收入分类，例如工资、奖金、投资等；分类列表应按当前类型过滤。
2. 返回按钮使用文本 `<`，视觉上比较粗糙，建议换成统一返回图标或按钮样式。
3. 分类 chip 数量很多，缺少搜索、分组或折叠，长列表浏览压力较大。
4. 添加区只有 placeholder，缺少固定字段说明。

### Launch 和 Second

记录：
1. `Launch` 是启动中转页；当前设备已保存隐私同意状态，冷启动抢拍直接进入今天页，未稳定截到启动页。
2. `Second` 在 `main_pages.json` 中注册，但代码搜索未发现实际路由入口；本次按不可达页面记录，未截图。

## 建议修复优先级

P0：
1. 分类管理按当前支出/收入类型过滤分类列表。
2. 隐私政策、服务协议增加统一返回入口。

P1：
1. 今天页标题改为中文。
2. 提升底部导航未选中态对比度。
3. 收敛设置页中邀请码区域和普通设置行之间的风格差异。
4. 优化账号页字段文案，弱化 OpenID。

P2：
1. 优化各页顶部留白。
2. 为隐私政策和服务协议增加小标题。
3. 分类管理增加搜索或分组。
